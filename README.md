# Axiom Translator

**Axiom Translator** — Chrome-расширение для **Axiom Trade**, которое переводит **основной текст** постов из X/Twitter **прямо внутри карточки поста**, когда она всплывает на графике или в ленте Axiom.

Никаких боковых панелей и отдельных всплывающих окон: текст твита заменяется переводом на своём месте, а всё остальное — аватар, шапка, лайки/репосты, фото, видео, вложенные цитаты и встроенные rich-превью — остаётся нетронутым.

## Возможности

- **Перевод inline, без side-панели.** Текст поста подменяется переводом прямо в оригинальной карточке твита — там же, где Axiom показывает её при наведении на график или в ленте.
- **Перевод на русский или украинский.** Язык перевода задаётся переключателем в настройках (RU или UA), меняется мгновенно — уже открытые карточки на странице сразу перепереводятся.
- **Переводится только основной текст поста.** Вложенная цитата (reply/quote) намеренно остаётся на языке оригинала — граница между «где кончается основной твит и начинается цитата» определяется эвристически по тексту карточки, и попытки автоматически переводить цитату на разных карточках Axiom приводили к путанице (не тот текст, задвоение, поломка вёрстки). Текст цитаты по-прежнему корректно вычитается из перевода основного поста, так что он не просачивается в текст.
- **Не трогает медиа и встроенные rich-блоки.** Фото, видео, превью внешних ссылок (сайт + картинка + заголовок) и любые другие визуально обособленные блоки с собственной рамкой внутри карточки (например, встроенный скриншот переписки с AI) не затрагиваются при вставке перевода — расширение переводит только сам текст поста.
- **Многоабзацные посты.** Переносы строк и разбивка на абзацы сохраняются.
- **Кликабельные ссылки внутри перевода** — реальные `href` сохраняются на своих местах в переведённом тексте. Очень короткие фрагменты ссылок (кэштеги вроде `$NI`, короткие тикеры) намеренно не оборачиваются в ссылку — перевод таких коротких токенов слишком часто ломает маркер-разметку, поэтому они остаются как обычный текст.
- **Детект через MutationObserver**, а не через положение курсора — карточка ловится независимо от того, где на странице она физически всплывает (включая тултипы поверх графика).
- **Устойчивость к перезагрузке расширения.** Если расширение обновилось/перезагрузилось, пока вкладка открыта, скрипт перестаёт долбить недоступный `chrome.runtime` и один раз предупреждает в консоли, что нужно обновить страницу.
- **Минималистичный тёмный монохромный popup** с настройками расширения.

## Как это работает

1. Открой **Axiom Trade**.
2. Наведи курсор на пост из X/Twitter (в ленте или во всплывающей карточке на графике).
3. Основной текст поста автоматически заменяется переводом прямо в карточке — без каких-либо дополнительных окон. Вложенная цитата (если есть) остаётся как есть, в оригинале.
4. Уже переведённый пост не переводится повторно при повторном наведении.

## Для чего это нужно

Расширение создано для того, чтобы читать посты в Axiom быстрее и удобнее, без переключения на сторонние переводчики и без визуального шума от дополнительных всплывающих панелей.

## Установка

### Вариант 1 — через ZIP

1. Скачай проект архивом или как папку.
2. Распакуй его на компьютер.
3. Открой в Chrome страницу: `chrome://extensions/`
4. Включи **Режим разработчика**.
5. Нажми **Загрузить распакованное расширение**.
6. Выбери папку с расширением.

### Вариант 2 — через Git

```bash
git clone https://github.com/USERNAME/axiom-translator.git
cd axiom-translator
```

Дальше:

1. Открой `chrome://extensions/`
2. Включи **Режим разработчика**
3. Нажми **Загрузить распакованное расширение**
4. Выбери папку проекта / папку расширения

## Использование

- Открой Axiom Trade.
- Наведи курсор на интересующий пост.
- Перевод появится прямо в тексте поста — обычно почти сразу, при повторных запросах перевод дополнительно кэшируется.
- Если перевод не удался (например, сбой сети), расширение автоматически повторит попытку при следующем обнаружении карточки — без ручного вмешательства.

## Настройки

Popup расширения — минималистичный тёмный интерфейс, в нём доступны:

- **Переводчик** — общий выключатель (вкл/выкл).
- **Сохранять ссылки** — оставлять ли реальные `href` кликабельными внутри перевода.
- **Язык** — направление перевода: RU или UA. Смена языка сразу переводит заново все уже открытые карточки на странице.

## Как расширение решает, что переводить

Определение частей карточки полностью эвристическое (жёстко заданных CSS-селекторов Axiom не используется, так как разметка отличается от карточки к карточке):

- **Карточка твита** — распознаётся по наличию `@handle`, позиционированию как floating overlay (`position: fixed/absolute`, а не строка в потоке документа — это отсекает строки таблиц holders/traders/pulse) и минимальной длине текста.
- **Основной текст** — самый маленький «листовой» текстовый элемент (без блочных дочерних тегов — только `a`, `span`, `b`, `br` и т.п.) с длиной текста, сопоставимой с ожидаемой длиной поста, исключая шапку, аватар (в том числе CSS-фон и SVG), медиа, превью-ссылку, встроенные rich-блоки с рамкой и блок цитаты.
- **Что исключается из текста и перевода:** шапка автора (имя/handle/дата), счётчики (лайки/репосты/просмотры), медиа-вложения (включая их alt-текст), превью-ссылки, встроенные rich-карточки с рамкой, собственный toggle X «Translate post / Hide Translation» вместе с дублирующим машинным переводом под ним, и текст вложенной цитаты.

## Ограничения

- Работа зависит от структуры DOM внутри карточек Axiom / X — расширение использует эвристики, а не жёстко заданные селекторы, поэтому в редких случаях авто-детект текста может не сработать на нетипичной карточке (в консоли появится `text container not found` — это безопасный отказ, а не ошибка, ничего не переводится и не ломается).
- Вложенная цитата принципиально не переводится (см. «Возможности» выше).
- Иногда возможны ошибки перевода из-за сети, лимитов API или нестабильной структуры источника.
