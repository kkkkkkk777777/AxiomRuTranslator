# Axiom Translator

**Axiom Translator** — Chrome-расширение для **Axiom Trade**, которое переводит посты из X/Twitter **прямо внутри карточки поста**, когда она всплывает на графике или в ленте Axiom.

Никаких боковых панелей и отдельных всплывающих окон: текст твита заменяется переводом на своём месте, а всё остальное — аватар, шапка, лайки/репосты, фото, видео и карточки внешних ссылок — остаётся нетронутым.

## Возможности

- **Перевод inline, без side-панели.** Текст поста подменяется переводом прямо в оригинальной карточке твита — там же, где Axiom показывает её при наведении на график или в ленте.
- **Направление перевода EN ⇄ RU.** Язык перевода задаётся переключателем в настройках (RU или EN).
- **Работает с медиа и превью-ссылками.** Фото, видео и карточки превью внешних сайтов (например, статья с whitecoatwaste.org) не затрагиваются при вставке перевода — расширение переводит только сам текст поста.
- **Многоабзацные посты.** Переносы строк и разбивка на абзацы сохраняются.
- **Кликабельные ссылки внутри перевода** — реальные `href` сохраняются на своих местах в переведённом тексте.
- **Вложенные quoted/reply-посты** переводятся отдельно, без перестройки их собственной шапки.
- **Детект через MutationObserver**, а не через положение курсора — карточка ловится независимо от того, где на странице она физически всплывает (включая тултипы поверх графика).
- **Минималистичный тёмный монохромный popup** с настройками расширения.

## Как это работает

1. Открой **Axiom Trade**.
2. Наведи курсор на пост из X/Twitter (в ленте или во всплывающей карточке на графике).
3. Текст поста автоматически заменяется переводом прямо в карточке — без каких-либо дополнительных окон.
4. Вложенный quoted-пост, если он есть, переводится отдельно тем же способом.
5. Уже переведённый пост не переводится повторно при повторном наведении.

## Для чего это нужно

Расширение создано для того, чтобы читать посты в Axiom быстрее и удобнее, без переключения на сторонние переводчики и без визуального шума от дополнительных всплывающих панелей.

## Установка

### Вариант 1 — через ZIP

1. Скачай проект архивом или как папку.
2. Распакуй его на компьютер.
3. Открой в Chrome страницу: `chrome://extensions/`
4. Включи **Режим разработчика**.
5. Нажми **Загрузить распакованное расширение**.
6. Выбери папку с расширением.

### Вариант 2 — через Git

```bash
git clone https://github.com/USERNAME/axiom-translator.git
cd axiom-translator
```

Дальше:

1. Открой `chrome://extensions/`
2. Включи **Режим разработчика**
3. Нажми **Загрузить распакованное расширение**
4. Выбери папку проекта / папку расширения

## Использование

- Открой Axiom Trade.
- Наведи курсор на интересующий пост.
- Перевод появится прямо в тексте поста — обычно почти сразу, при повторных запросах перевод дополнительно кэшируется.
- Если перевод не удался (например, сбой сети), расширение автоматически повторит попытку при следующем обнаружении карточки — без ручного вмешательства.

## Настройки

Popup расширения — минималистичный тёмный интерфейс, в нём доступны:

- **Переводчик** — общий выключатель (вкл/выкл).
- **Сохранять ссылки** — оставлять ли реальные `href` кликабельными внутри перевода.
- **Язык** — направление перевода, EN или RU.

## Ограничения

- Работа зависит от структуры DOM внутри карточек Axiom / X — расширение использует эвристики (текстовые метки, размеры блоков, наличие `<img>`/внешних ссылок), а не жёстко заданные селекторы, поэтому в редких случаях авто-детект текста может не сработать на нетипичной карточке.
- Иногда возможны ошибки перевода из-за сети, лимитов API или нестабильной структуры источника.
